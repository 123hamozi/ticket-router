# AI-маршрутизатор тикетов поддержки

## Описание решения
Данный проект представляет собой минимальный работающий прототип (PoC) системы автоматизации обработки тикетов поддержки. Архитектура базируется на концепции двухуровневой фильтрации (Fast & Slow Paths), что позволяет безопасно обрабатывать пиковые нагрузки до 20 000 обращений за 10 минут.

## Бизнес-ценность
Внедрение данной ML-системы направлено на прямую экономию фонда оплаты труда первой линии поддержки. За счет уверенной автоматической маршрутизации типовых обращений система обрабатывает инциденты без привлечения операторов. Снижение доли ручной обработки рутинных задач позволяет компании масштабироваться без пропорционального расширения штата сотрудников. Выбор классического ML-подхода вместо LLM сводит к минимуму стоимость инфраструктуры, обеспечивая быстрый и прогнозируемый возврат инвестиций.

## Инструкция по запуску
Проект упакован в контейнер для быстрого развертывания.
Выполните команду в терминале: `docker-compose up --build`
API будет доступно по адресу: `http://localhost:8000/docs`

## Демонстрируемые сценарии
В рамках PoC подтверждаются два ключевых потока:
* Успешный сценарий (Happy Path): Тикет классифицируется с вероятностью выше порога (0.85) и автоматически маршрутизируется.
* Сценарий риска (Fallback Path): Модель демонстрирует низкую уверенность, автоматическое решение блокируется, и тикет эскалируется на оператора (human-in-the-loop).

## Границы прототипа (Design vs. Reality)
* Реализовано в коде (Реальность): FastAPI-приложение, модуль деидентификации (PII Scrubber), логика маршрутизации по порогу уверенности и smoke-тесты.
* Архитектурный дизайн (Mocked): Очереди сообщений (RabbitMQ), реляционная база данных и инференс обученной scikit-learn модели заменены детерминированными заглушками.

## Допущения и ограничения
* Предполагается, что на стороне клиентов реализована логика повторных запросов (retries) на случай HTTP 429 при пиковых всплесках.
* Базовый модуль PII маскирует только телефоны и email; для production потребуется интеграция с полноценной NER-моделью.
